# Браузерные тесты

Тесты на Playwright (Chromium). Каждый скрипт оборачивает `game/neon-td.html` в страницу так же, как это делает хост артефакта, и складывает служебные файлы и снимки экрана в `tests/out/` (папка в .gitignore). Любой тест принимает путь к другой сборке первым аргументом.

| Скрипт | Что проверяет | Запуск |
| --- | --- | --- |
| `flow1.py` | лобби, первый запуск, бой, кольцо постройки, развилки, боссы, задания, бесконечный режим, вызов дня, кодекс | `python3 tests/flow1.py` |
| `flow2.py` | профиль, титулы, арсенал и облики, сезон, вызов недели, таблица, облачное сохранение (`--mock` имитирует базу артефакта) | `python3 tests/flow2.py --mock` |
| `flow3.py` | версии 12–13: второй круг и лечение босса, брифинги, невидимки, экономика и перенос опыта сезона, магазин, возврат ядер, слияние облака | `python3 tests/flow3.py 360` (ширина экрана, по умолчанию 390) |
| `ux.py` | разметка всех экранов на 5 размерах: мелкие кнопки, обрезанный текст, контраст, выход за край | `python3 tests/ux.py - s360,i390` (`-` значит текущая игра; без списка все 5 размеров) |
| `ring.py` | кольцо постройки у краёв поля | `python3 tests/ring.py` |
| `chaos.py`, `chaos2.py` | случайные нажатия в бою и лобби с проверкой инвариантов: нет NaN, двух башен на клетке, отрицательных кредитов | `python3 tests/chaos2.py - 90` |
| `perf.py` | частота кадров и память в тяжёлых сценах | `python3 tests/perf.py` |
| `storage.py` | работа без localStorage: запрет, null, переполнение | `python3 tests/storage.py` |

Тест считается пройденным, если в последней строке `N ok, 0 bad` и пустой список `ERRORS`. Ошибка загрузки шрифтов Google без сети не считается ошибкой игры.
