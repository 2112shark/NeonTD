# CLAUDE.md — «Неоновый рубеж»

Контекст и правила для сессий Claude, которые работают с этим репозиторием. Читать целиком перед первой правкой.

## Общение

- Отвечать только по-русски. Если пользователь пишет по-английски, сначала перевести текст на русский, потом выполнять.
- Отчёт после работы короткий: что изменилось, цифры до и после, что осталось. Если данные симулятора говорят против утверждённого решения, предложить вариант с цифрами и дождаться ответа, а не менять дизайн молча.

## Что это

Мобильная tower defense в одном HTML-файле: кампания из 15 миссий в 3 главах с боссами в миссиях 5, 10 и 15, «Кошмар», бесконечный режим, вызов дня и вызов недели с лигами и общей таблицей. Мета: лаборатория за ядра данных, мастерство и облики башен, сезонный трек на 28 дней, задания, достижения, звания, магазин обликов, облачное сохранение.

- Живая версия: https://claude.ai/artifact/2viAoFJJt2RHnJjxqfSWgz. Это приватный артефакт Claude, сейчас Version 13; в игре подпись «версия 9».
- Отчёт аудита: «Неоновый рубеж: аудит игры», https://claude.ai/artifact/6i6qgiC88QTQtX2iHbVyEo (Claude Docs: doc id `2e3ac959-8681-4ea6-a397-23b6664e6840`, вкладка `901d93da-2bc1`, тело `7a2a1caa-3064`). Копия без графиков лежит в `docs/audit-report.md`.

## Структура

- `game/neon-td.html` — игра целиком, единственный исходник; именно он публикуется в артефакт.
- `index.html` — та же игра полной страницей для GitHub Pages. Генерируется `python3 tools/build_standalone.py`, руками не править; `node tools/check.js` падает, если файл устарел.
- `docs/spec.md` — справочник данных (башни, враги, миссии, лаборатория, перки, сезон, магазин). Генерируется: `node tools/spec.js > docs/spec.md`.
- `docs/balance.md` — результаты симуляций версий 11–13 и методика.
- `docs/roadmap.md` — что делать дальше, с приоритетами.
- `docs/changelog.md` — история версий.
- `docs/history/` — скрипты правок версий 11–13, для справки.
- `tools/check.js` — синтаксис, дымовой прогон и проверка, что `index.html` собран из текущей игры. `tools/build_standalone.py` — сборка `index.html`.
- `tools/sim/` — симулятор баланса: боты четырёх уровней играют настоящим кодом игры без браузера. Инструкция в `tools/sim/README.md`.
- `tests/` — браузерные тесты на Playwright, инструкция в `tests/README.md`.
- `data/v11`, `data/v12`, `data/v13` — сохранённые результаты прогонов, база для сравнения.

## Как устроен код

Файл — HTML-фрагмент без `<!doctype>`: `<title>`, шрифты Google, `<style>`, разметка и один `<script>` с IIFE. Каркас страницы добавляет хост артефакта.

Порядок внутри скрипта:
1. Утилиты; прогресс игрока `PROG` (`freshProg`, localStorage-ключ `neon-rubezh-v2`, `saveProg`).
2. Данные: `LAB_BR`/`LAB`, `ACH`, `MAPS`, `TD` (башни), `TW_UNLOCK`, `SYN`, `ED` (враги), `BOSSES`, `BOSS_LAP`, `BOSS_LAP_HEAL`, `MODS`, `CLOAK_NEAR`, `AB`, `CHAPTERS`, `MISSIONS`, `NM`, `BL` (реплики боссов), `PERKS`, `QD`/`QW` (задания), `SKINS`, `KFX`, `SEASONS`, `SHOP`, `LEAGUES`.
3. Сезон: `seasonInfo`, `tierStart`, `tierOf`, `seasonMigrate`, `seasonState`, `addXP`, `grantTier`, `dupRew`; магазин: `shopBuy`, `shopSeasonTier`, `ptsFree`.
4. Облако: `NET`, `netInit`, `cloudLoad`, `cloudSave`, `mergeProg`, таблица недели.
5. Бой: `newGame`, `startWave`, `genWave`, `waveMods`, `spawn`, `moveE` (прорывы и второй круг босса), `update` (видимость невидимок, конец волны, опыт), `endGame`, постройка, перки, способности, отрисовка.
6. Лобби: состояние `LBY`, экраны `SCR.home/camp/mission/endless/daily/weekly/lab/awards/profile/codex/more`, хуки `POST`, `go(screen)`, диспетчер `act(a,v)` для атрибутов `data-act="имя:значение"`, `updBadges`, `showResults`.
7. `loop`, затем `window.__td`: хуки для тестов и симулятора.

Реплики оператора ВЕГИ выводит `say(text)`. Все тексты на русском. Брифинги миссий (`goalLong`), кодекс, описания перков и реплики должны совпадать с тем, что делает код.

## Прогресс и облако

- `PROG` хранится в localStorage и в облаке артефакта. Через `claude.use('db')` лежит документ `data/users/<id>/save`, таблица недели — коллекция `scores`; имя игрока берётся из `claude.use('user')`.
- Правила доступа артефакта: `scores` читают все зрители, пишет владелец; `scores/{self}` пишет каждый игрок.
- Новое поле `PROG` добавлять в трёх местах: `freshProg()`, цикл нормализации объектов после загрузки и `mergeProg`. В `mergeProg` для владений и покупок нужно объединение, для счётчиков максимум. Иначе поле потеряется при синхронизации устройств.
- Опыт сезона хранится в шкале версии 12 (флаг `e2`). `seasonMigrate` переводит старые сохранения с `S_OLD=250` без потери ступеней, `mergeProg` мигрирует обе копии перед сравнением. Награды выдаются только за ступени больше `got`.

## Порядок работы над изменением

1. Правка `game/neon-td.html`: точечные Edit или python-скрипт с проверкой числа вхождений каждой замены (образцы в `docs/history/`). Затем `python3 tools/build_standalone.py`, чтобы обновить `index.html`.
2. `node tools/check.js`.
3. Тесты: `python3 tests/flow1.py`, `python3 tests/flow2.py --mock`, `python3 tests/flow3.py 360`. При изменениях интерфейса добавить `python3 tests/ux.py - s360,i390`, перед публикацией прогнать `python3 tests/chaos2.py - 90`.
4. Баланс: прогон в `tools/sim` и сравнение с `data/` (`python3 tools/sim/report.py`). Для решения нужно минимум 20 боёв на точку: результаты не детерминированы полностью.
5. Документы: `docs/changelog.md`, при изменении баланса `docs/balance.md`, затем `node tools/spec.js > docs/spec.md`. Поднять подпись версии в `<p class="ver">`.
6. Публикация через Artifact: `file_path` = `game/neon-td.html`, `url` = https://claude.ai/artifact/2viAoFJJt2RHnJjxqfSWgz, `label` вида «Версия N: …». Без `url` создаётся отдельная копия, так уже было один раз. `capabilities` и `icon` не передавать: правила базы и доступ к профилю переносятся сами.
7. Отчёт пользователю по-русски, при необходимости обновить отчёт аудита инструментами Claude Docs.

## Подводные камни

- `tools/sim/sim.js` встраивает хуки в код игры по точным строкам: `const ci=e.rt.core||0;`, регулярное выражение для `const rw=e.rw+(hasP('bounty')?N:0);S.gold+=rw;`, `if(it>0){S.gold+=it;`, `if(eb>0){S.gold+=eb;`. Если меняете эти строки, обновите `inject()`. Строка `const ci=e.rt.core||0;` должна встречаться в игре ровно один раз.
- `tools/spec.js` экспортирует внутренние константы вставкой перед `window.__td={`. При переименовании констант поправьте `EXPORT`.
- `pkill -f <шаблон>` завершает и собственную оболочку, если шаблон есть в команде. Останавливать процессы по PID.
- Карьеры и матрицу запускать в фоне через `nohup`. В облачной среде 2 CPU, один бой занимает около 1,5 с.
- Chromium для Playwright в облачной среде уже стоит в `/opt/pw-browsers`, `playwright install` там не запускать. Ошибка загрузки шрифтов `ERR_TUNNEL_CONNECTION_FAILED` в тестах — особенность песочницы.

## Решения, согласованные с владельцем

- Боссы миссий на обычной сложности: первый прорыв стоит 10 прочности ядра, босс восстанавливает 30% здоровья и идёт на второй круг, второй прорыв означает поражение. В «Кошмаре» прорыв сразу означает поражение. Перк «Аварийный щит» босса миссии не блокирует.
- Невидимок видят Крио и Тесла во всей зоне и любая башня на расстоянии до 1,5 клетки.
- Сезон: ступень 750 опыта, первые пять по 350; волна 4 опыта, первая победа в вызове дня 150, задание дня 100, задание недели 400.
- Магазин в «Лаборатории»: эффекты 15 ядер, облики 30, облики только для магазина 60. Награды идущего сезона не продаются. Если купленная вещь выпала на треке, ядра возвращаются.
- Что делать дальше: `docs/roadmap.md`.
