# Скрипты правок версий 11–13

Каждый скрипт применялся к предыдущей опубликованной версии игры и менял её точными заменами с проверкой числа вхождений: если фрагмент не найден или найден не один раз, скрипт останавливается.

| Файл | Версия | Что делает |
| --- | --- | --- |
| `v11_patch3.py` | 11 | исправления интерфейса после аудита |
| `v12_patch4.py` | 12 | первый приоритет: второй круг босса, невидимки, экономика сезона, магазин |
| `v13_patch5.py` | 13 | лечение босса на втором круге |

Повторно их не запускать: изменения уже в `game/neon-td.html`. Они нужны как подробная запись того, что и где менялось, и как образец для пакетных правок.
