# Симулятор баланса

`sim.js` загружает `game/neon-td.html` в Node (модуль `vm`, страница без браузера с заглушками DOM), вставляет несколько хуков для учёта доходов и прорывов и играет настоящим кодом игры за ботов четырёх уровней: `beginner`, `novice`, `average`, `expert`. Уровни описаны в `docs/balance.md`.

Результаты пишутся в `tools/sim/out/` (папка в .gitignore). Другая папка задаётся через `SIM_OUT`, другая сборка игры через `TD_HTML`, например для сравнения варианта с текущей версией:

```bash
TD_HTML=/path/to/variant.html SIM_OUT=/tmp/variant node tools/sim/bossfocus.js 20 beginner,novice
```

## Скрипты

| Скрипт | Что считает | Запуск | Время на 2 CPU |
| --- | --- | --- | --- |
| `bossfocus.js` | доля побед на боссах (миссии 5, 10, 15), прорывы, звёзды | `node bossfocus.js [N=20] [типы]` | 4 типа × 20 боёв ≈ 6 мин |
| `matrix.js` | все 15 миссий для одного типа игрока | `node matrix.js <тип> none\|career\|full [N=10] [nm]` | ≈ 4 мин на тип |
| `career.js` | прохождение кампании с сохранением прогресса, затем «Кошмар» | `node career.js <тип> [K=6]`; `MAXA` — попыток на миссию, `NOLAB=1` без лаборатории | 8 карьер ≈ 6–12 мин на тип |
| `chal.js` | вызов дня на 28 дней или неделю на 26 недель | `node chal.js daily\|weekly` | daily ≈ 5 мин, weekly ≈ 30 мин |
| `weekly_mods.js` | только недели с заданным модификатором | `node weekly_mods.js [cloak]` | ≈ 5 мин |
| `strat.js` | сборки башен в бесконечном режиме | `node strat.js` | долго, запускать в фоне |
| `perk.js` | вклад каждого перка на миссиях 11 и 13 | `node perk.js` | ≈ 15 мин |
| `endless.js` | рекорды бесконечного режима | `node endless.js` | долго |
| `build_tab.py` | таблица карьер для модели темпа | `python3 build_tab.py [папка]` | секунды |
| `pacing.py` | темп сезона и ядер для четырёх видов игроков на 84 дня | `python3 pacing.py [папка с career_tab.json и chal_daily.json]` | секунды |
| `report.py` | таблицы сравнения версий из `data/` | `python3 report.py` | секунды |

Долгие прогоны запускайте в фоне: `nohup node career.js beginner 8 2>career.log &`.

## Типичный цикл проверки правки баланса

1. `node bossfocus.js 20` и `node matrix.js <тип> career 10` для затронутых типов игроков.
2. Если правка влияет на кампанию: `node career.js <тип> 8` для всех четырёх типов, `python3 build_tab.py`, затем `node chal.js daily` и `python3 pacing.py`.
3. Сравнить с `data/` и сохранить новые результаты в `data/vNN/`, обновить `docs/balance.md`.

## Что учитывать

- Код игры использует `Math.random`, поэтому прогоны не повторяются бит в бит; разброс — один-два боя из 20.
- Хуки в `inject()` ищут в коде игры точные строки. Если вы их меняете, обновите `inject()`, иначе `load()` упадёт с сообщением `hook 0x` или `hook 2x`.
- Боты не учатся на ошибках. Сравнивать версии между собой ими можно, абсолютные проценты нужно сверять с реальными игроками.
