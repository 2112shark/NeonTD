# Неоновый рубеж (NeonTD)

Браузерная tower defense в неоновом аркадном стиле для телефона и компьютера. Вся игра — один HTML-файл без сборки и зависимостей; подключаются только шрифты Google Fonts.

## Запуск

- **В Claude:** https://claude.ai/artifact/2viAoFJJt2RHnJjxqfSWgz. Это приватный артефакт: другие люди откроют его, только если им поделиться.
- **Локально:** открыть `index.html` в браузере или поднять сервер `python3 -m http.server 8000` и открыть http://localhost:8000.
- **GitHub Pages:** включите Pages для основной ветки, `index.html` лежит в корне.

## Сохранения

Прогресс хранится в `localStorage` браузера. Облачное сохранение и таблица вызова недели работают, только когда игра открыта как артефакт в Claude (через `window.claude`); вне Claude они отключаются, а игра остаётся полностью рабочей.

## Что в игре

- Кампания: 15 миссий в 3 главах, боссы в миссиях 5, 10 и 15, три звезды за миссию, «Кошмар» для пройденных миссий.
- Бесконечный режим на 3 картах, вызов дня с серией побед, вызов недели с очками, лигами и общей таблицей.
- 7 башен по 3 уровня и по 2 специализации, синергии соседних башен, 20 перков, 3 способности.
- Мета: лаборатория из 13 улучшений за ядра данных, мастерство и облики башен, сезонный трек из 30 ступеней на 28 дней, задания дня и недели, 41 достижение, звания, магазин обликов и эффектов.
- Кодекс башен и врагов, адаптивный интерфейс, горячие клавиши.

Все данные игры собраны в [docs/spec.md](docs/spec.md).

## Структура

| Путь | Содержимое |
| --- | --- |
| `game/neon-td.html` | исходник игры: фрагмент, который публикуется в артефакт Claude |
| `index.html` | та же игра в виде полной страницы для GitHub Pages и запуска вне Claude; собирается командой `python3 tools/build_standalone.py` |
| `docs/spec.md` | справочник механик, генерируется из кода |
| `docs/balance.md` | результаты симуляций баланса, версии 11–13 |
| `docs/roadmap.md` | план доработок с приоритетами |
| `docs/changelog.md` | история версий |
| `docs/audit-report.md` | копия отчёта аудита без графиков |
| `docs/history/` | скрипты правок версий 11–13 |
| `tools/check.js` | проверка синтаксиса, дымовой прогон и актуальности `index.html` |
| `tools/spec.js` | генератор `docs/spec.md` |
| `tools/build_standalone.py` | сборка `index.html` |
| `tools/sim/` | симулятор баланса: боты, карьеры, вызовы, модель темпа |
| `tests/` | браузерные тесты на Playwright |
| `data/` | результаты прогонов по версиям |
| `CLAUDE.md` | контекст и правила для сессий Claude |

## Проверка

Нужны Node 18+ и Python 3.10+ с Playwright: `pip install -r requirements.txt`, затем `playwright install chromium`.

```bash
node tools/check.js            # синтаксис, дымовой прогон, index.html совпадает с game/neon-td.html
python3 tests/flow1.py         # лобби, бой, кампания, задания
python3 tests/flow2.py --mock  # профиль, арсенал, сезон, неделя, облако (с имитацией базы)
python3 tests/flow3.py 390     # второй круг босса, невидимки, сезон, магазин
```

Симулятор баланса описан в [tools/sim/README.md](tools/sim/README.md), тесты в [tests/README.md](tests/README.md).
