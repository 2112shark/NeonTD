# Неоновый рубеж (NeonTD)

Браузерная tower defense в неоновом аркадном стиле: кампания с главами и боссами, режим «Кошмар», бесконечный режим, вызов дня и недельное испытание с лигами, лаборатория, арсенал, перки, сезон, задания, достижения и кодекс.

## Запуск

Нужен Node.js 20+.

```bash
npm install
npm run dev        # дев-сервер с горячей перезагрузкой, http://localhost:5173
npm run build      # сборка в dist/
npm run preview    # посмотреть собранную версию
```

`dist/` — статичный сайт: его можно выложить на GitHub Pages или любой хостинг (пути относительные).

## Тесты и типы

```bash
npm run typecheck  # проверка типов (TypeScript по JS + JSDoc)
npm test           # юнит-тесты логики (Vitest + jsdom)
npm run test:e2e   # браузерные тесты (Playwright): сборка, лобби, бой, пауза
```

Перед первым запуском e2e: `npx playwright install chromium`. Если Chromium уже установлен, путь к нему можно передать через `PW_CHROMIUM`.

CI (`.github/workflows/ci.yml`) гоняет оба набора на каждый push и pull request.

## Публикация

`.github/workflows/pages.yml` собирает игру и выкладывает её на GitHub Pages при каждом push в основную ветку репозитория. Один раз нужно включить Pages: Settings → Pages → Build and deployment → Source: **GitHub Actions**. Адрес: `https://2112shark.github.io/NeonTD/`.

## Структура

```
index.html            разметка: HUD, поле, панель, оверлеи, лобби
src/
  main.js             точка входа и игровой цикл
  core/               правила игры: состояние забега, бой, волны, экономика, карты
  data/               чистые данные: башни, враги, карты, миссии, перки, задания
  meta/               прогрессия вне боя: сохранения, лаборатория, сезон, вызовы, достижения
  render/             отрисовка на canvas
  ui/                 интерфейс боя; ui/lobby/ — экраны лобби
  audio/              звук (WebAudio)
  input.js            мышь, тач, клавиатура
  testHook.js         window.__td — доступ к состоянию для тестов и отладки
  styles/             CSS по экранам, порядок подключения в index.css
tests/
  unit/               логика без браузера
  e2e/                сценарии в настоящем браузере
```

Типы и перевод на TypeScript идут постепенно:
- уже на TypeScript: `src/data/` (таблицы с явными типами `TowerDef`, `EnemyDef`, `Mission`, `Perk`, `QuestDef`…), весь `src/core/` (бой, волны, экономика, карты, состояние забега) и `meta/daily`. Эти файлы проверяются в строгом режиме (`tsconfig.strict.json`);
- остальное пока на JS: TypeScript проверяет его в мягком режиме через `checkJs`, аннотации в JSDoc;
- `src/types.d.ts` описывает состояние боя (`RunState`), башню, врага, карту и прогресс игрока (`Progress`). Новое поле состояния сначала добавляется в тип, иначе `npm run typecheck` упадёт.

Перевод следующего модуля: переименовать `.js` → `.ts`, поправить пути импорта на `.ts`, расставить типы до чистого `npm run typecheck`.

Общее состояние экспортируется как live-binding (`S`, `PROG`, `speed` и др.). Если переменную нужно переприсвоить из другого модуля, у неё есть сеттер (`setPROG`, `setSpeed`, `setMuted`, `setRadKey`).

## Сохранения

Прогресс хранится в `localStorage`. Таблица лидеров и облачное сохранение работают только тогда, когда игра открыта как Artifact в Claude (через `window.claude`). Вне Claude они отключаются, а игра остаётся полностью рабочей. Все сетевые функции собраны в `src/meta/net.js`: это место для подключения своего бэкенда.
