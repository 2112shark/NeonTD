# Неоновый рубеж (NeonTD)

Браузерная tower defense в неоновом аркадном стиле. Вся игра — один файл `index.html` без сборки и зависимостей (подключаются только шрифты Google Fonts).

## Запуск

- Открыть `index.html` в браузере, или
- поднять локальный сервер: `python3 -m http.server 8000` → http://localhost:8000

Подходит для GitHub Pages: включите Pages для ветки, `index.html` лежит в корне.

## Что внутри

- Кампания с главами, миссиями, боссами и звёздами, режим «Кошмар»
- Вызов дня и еженедельное испытание с лигами
- Лаборатория (прокачка за ядра), арсенал, перки, сезон, задания дня
- Награды, звания, кодекс башен и врагов
- Адаптивный интерфейс для телефона и десктопа, горячие клавиши

## Сохранения

Прогресс хранится в `localStorage` браузера. Таблица лидеров и облачное сохранение работают, только когда страница открыта как Artifact в Claude (через `window.claude`); вне Claude они автоматически отключаются, игра остаётся полностью рабочей.
