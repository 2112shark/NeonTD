# Результаты прогонов

Сохранённые выходы симулятора, база для сравнения после новых правок. Сводные таблицы: `python3 tools/sim/report.py`.

| Папка | Сборка | Файлы |
| --- | --- | --- |
| `v11/` | версия 11 (до первого приоритета) | `career_tab.json`: карьеры (начинающий и новичок 8 штук, средний и опытный из аудита); `bossfocus.json`: боссы, по 20 боёв начинающего и новичка; `chal_daily.json`: вызов дня, 28 дней; `weekly_cloak.json`: 6 недель с невидимками; `pacing.json`: модель темпа; `mx_*_career.json`, `mx_*_none.json`: матрица кампании, по 10 боёв на миссию, с типичной лабораторией и без неё |
| `v12/` | версия 12 (второй круг без лечения) | те же файлы: `bossfocus.json` по всем четырём типам игроков, карьеры, вызов дня, неделя с невидимками, модель темпа, матрица кампании с лабораторией |
| `v13/` | версия 13 (лечение босса 30%) | `bossfocus.json` для начинающего и новичка, `career_tab.json` и `pacing.json`; вызовы дня и недели от лечения босса не зависят, для них действуют данные v12 |
| `audit/` | аудит перед версией 11 | сборки башен (`strat.json`), перки (`perk.json`), бесконечный режим (`endless.json`), производительность (`perf.json`), вызов недели за 26 недель (`chal_weekly.json`) |

Форматы описаны в начале соответствующих скриптов в `tools/sim/`.
